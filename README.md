# Alexandru Panta — Portfolio

My personal developer portfolio, presenting my work as a **full-stack developer focused on IoT, systems and security**.

🔗 **Live:** [portfolio-bice-nine-45.vercel.app](https://alexpanta.dev)

## ✨ Features

- Responsive single-page layout with smooth section scrolling
- About, Projects, Skills (Languages & Tools) and Contact sections
- Built with the Next.js App framework and deployed on Vercel

## 🛠️ Built with

- **Next.js** & **React**
- **FontAwesome** for iconography
- **react-scroll** for smooth in-page navigation
- **Vercel Analytics**
- **Jest** + Testing Library for tests

## 🚀 Run locally

```bash
# install dependencies
npm install

# start the dev server
npm run dev

# build for production
npm run build && npm start

# run tests
npm test
```

Then open [http://localhost:3000](http://localhost:3000).
